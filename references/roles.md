# 角色职责维度

> 触发条件：分配角色时、以及每个交接点验收时读。
> 角色到模型的对应关系在 `开题.md`；本卡只写**职责与验收维度**，与谁来执行无关。

一句话职责在交接时没法验收——「Coder 负责实现」，交回来的东西是好是坏没有对照物。
下面每张表就是该角色的**交接验收单**：逐条对照，缺项即退回。

单人单会话时一人兼所有角色，表照用；**唯一不能兼的是 Critic 与 Auditor**——
它们的全部价值在于没参与实现。

---

## Coordinator

读题、定规格、全程裁决与终裁。**唯一与使用者对话的角色**，其余角色的问题经它转达。

| # | 维度 | 验收 |
|---|---|---|
| C1 | 题面转录忠实 | 逐问原文转录，不改写不合并；可解释点标出来而不是替使用者拍板 |
| C2 | 赛制条款摘录 | 页数、图数、命名、匿名、AI 声明、模板与引擎全部抄进 `开题.md`，抄原文不凭印象 |
| C3 | PRD 与打磨关 | 每条完成标准能回答「怎么算过、谁来判、用什么命令判」；答不上来的不许留在 PRD |
| C4 | **建模思路** | 先认题型再选方法族；每问给一条**主路线**和至少一条**独立核验路线**（不同估计量／解析极限／暴力小实例）；承重假设写明「若它不成立，哪个结论先塌」 |
| C5 | 时间预算与冻结点 | 剩 30% 禁新增方法路线、剩 15% 只修阻断项、剩 5% 只编译合规打包 |
| C6 | 交接点验收 | 按各角色的维度表逐条核，缺项退回；不接受「看起来对」 |
| C7 | 降级裁决 | 哪些结论降级、降到什么措辞、记进降级声明——这是裁决不是执行方自便 |
| C8 | 终裁 | 复核意见处置完毕、门禁全绿、答案唯一性成立，才准打包 |

**交出**：PRD + 题面分析 + 填好的 `开题.md`。

---

## Modeler

执行前的读题与建模评审。**有异议就退回，不动手**——这一步的意义就是在花机时之前拦住。

> **它是复核者，不是原创者。** 建模思路由 Coordinator 提出（见 C4），Modeler 的职责是独立复核那份思路站不站得住。名字里的 Model 指它审的对象，不是它的产出。

| # | 维度 | 验收 |
|---|---|---|
| M1 | 题意有没有读偏 | 对象身份、判据定义、边界处理、单位与量纲，逐条能指到题面 |
| M2 | 方法族对不对 | 先认题型再选方法族；判定型/估计型/反解型/优化型/评价型不能混 |
| M3 | 完成标准可不可判 | PRD 每条标准都能落到一条命令或一个可观测量上 |
| M4 | 证书等级预告 | 这个方法能产出什么证书？产不出就换方法，或现在就预告论文降级措辞 |
| M5 | 跨问一致性 | 多问题目是否共用同一判定内核；各问分头实现＝口径必然漂移 |
| M6 | 机时可行性 | 外推是否基于**真实内核实测**；复杂度符号不算数 |
| M7 | 异议闭环 | 异议列成清单交回，不夹带自行修改；无异议要明说「可执行」 |

**交出**：异议清单 或「无异议，可执行」。

---

## Critic

对抗性审查。**必须由没参与实现的一方做**——作者复核自己的实现，看到的是「我以为我写了什么」。

**入口两问**：复现了吗？红绿了吗？——最容易查也最容易被跳过，所以放最前。
往下 R3–R10 逐条展开；对**方案本身**的第一性原理用 `first-principles-thinking`，本表不重述。

| # | 维度 | 验收 |
|---|---|---|
| R1 | 复现 | 换机器、换种子、解包后照说明跑，能否得到同一个数 |
| R2 | 红绿 | 每个断言先红过吗，还是写完实现才补的测试；expected 有没有来自被测代码 |
| R3 | 口径撞现实 | 每条口径挂的判别实验做了没有——只比较两个口径而不撞现实，两个都可能是错的 |
| R4 | 私货约束 | 每条模型约束能否指到题面原文；指不到即私货 |
| R5 | 量级外部对照 | 与解析界、粗模型或同领域尺度律比，差一个数量级必须停下查代码 |
| R6 | 退化与极限 | 规模推到物理上不可能的端点，结果是否仍合理且对判据敏感 |
| R7 | 声明强度 | 措辞强度不得高于证据强度；最优/证明/显著/必然逐处查 |
| R8 | 门禁真伪 | 记录里贴的是官方脚本的命令与退出码，还是自写替代品发给自己的通过 |
| R9 | 压力测试 | 至少应用一种并写明用了哪个与结论：**Pre-Mortem**（一年后它失败了，为什么）／**Inversion**（什么能保证失败，我们在做吗）／**Second-Order**（成了之后会引发什么）。方法详见 `first-principles-thinking` 的 Phase 5 |
| R10 | 反浅层 | 每条结论给**证据位置**（文件:行号／命令+退出码／数字）。「看起来没问题」「已检查」不算结论——审查也会浅得过关 |

**交出**：补充项清单，同步给执行方；改完重跑受影响的门禁，不是口头确认。

---

## Coder

实现与计算。产出的是**能被别人复算的数**，不是「跑出来了」。

| # | 维度 | 验收 |
|---|---|---|
| D1 | 共享内核 | 核心原语与判据在 `求解/core/`，各问 import；禁止逐问复制 |
| D2 | 神谕独立 | expected 来自手算、解析解或独立实现；先红后绿 |
| D3 | 先算后画 | 计算脚本只落盘结果；绘图脚本只读结果文件 |
| D4 | 长批可恢复 | 分块 ≤500 单元、原子落盘、启动扫描续跑；`batch_gate.py` 退出码 0 |
| D5 | 证书走官方 | 用 `certify.py` 出三态判定，不手写公式；选择与认证样本分离 |
| D6 | 语义主键 | 每条 authoritative 有 `scenario_id`，禁止按位置/顺序取值 |
| D7 | 失败如实记 | 跑挂的候选、放弃的路线、砍掉的样本量都要留痕，不许静默 |
| D8 | 入账冻结 | 合理性检查过关后 `ledger.py --validate` 再 `--freeze` |

**交出**：结果文件 + 冻结的账本 + 各 Gate 的命令与退出码。

## Illustrator

出图。图是论证链的一环，不是插画。

| # | 维度 | 验收 |
|---|---|---|
| I1 | 先有目的 | 每张图先写一句「要让评委看见什么」，并指到它支持的结论与账本键；写不出就不画 |
| I2 | 三套并行 | 主控一套、执行方一套、执行方模仿样例目录一套；生成对照页 |
| I3 | 数字来自账本 | 图里每个数必须能回读到账本；**长相可以仿，数字一个都不许仿** |
| I4 | 必被引用 | 生成的图要么进正文并配解读段，要么进补充附录并在正文指路，要么删除 |
| I5 | 字体与缺字 | 中文字体写成栈；出图后查豆腐块与 `Glyph missing`，禁止用忽略警告压掉 |
| I6 | 目检 | contact sheet 逐张过重叠、误差带、截断轴、图注自足、缩放比 |
| I7 | 门禁 | `figqa.py` 退出码 0（图数、正文引用数、空图、重复图、分辨率） |

**交出**：三套图 + 对照页 + `figqa` 报告。默认用第一套继续，选哪套由使用者事后指定。

## Writer

写作。正文里出现的每个数都必须是宏，不是手打。

| # | 维度 | 验收 |
|---|---|---|
| W1 | 先宏后文 | 先 `ledger.py --emit-tex` 生成宏，再动笔；正文只引用宏 |
| W2 | 摘要形态 | 每问一段五动作；加粗只允许三类各至多一处；页数由 `.aux` 程序化核实 |
| W3 | 结论醒目 | 每问末尾结论块三行（答案 + 证书 + 适用条件）；全文一张结果汇总表 |
| W4 | 检验章六小节 | 双路互证 / 可核事实对表 / 参数灵敏度 / 样本量与收敛 / 稳健性 / 适用边界 |
| W5 | 图后解读 | 每张正文图后紧跟「现象—原因—意义」；「如图 X 所示」不算解读 |
| W6 | 措辞不越级 | 强度不高于证据；未分辨的结论降精度报告并与降级声明一致 |
| W7 | 答案唯一 | 摘要、正文、图表、结论里是同一个数；互证值只出现在检验节并注明用途 |
| W8 | 篇幅取舍 | 不够就补附录不撑正文；删节判据是「删掉是否丢失证据链一环」，会丢就移不删 |

**交出**：论文 tex + `audit_numbers` 三向审计报告。

---

## Auditor

复核。拿**题面原文 + 全部交付物**核，只给论文核不了 A1。**不直接改稿**，出意见交回裁决。

| # | 维度 | 验收 |
|---|---|---|
| A1 | 最优解是否入文 | 账本里的 authoritative 答案与正文结论逐问一致；被选方案的最优性依据在文中可见 |
| A2 | 公式有无写坏 | 符号、下标、量纲、编号引用、跨章符号是否同义；渲染后逐个目检 |
| A3 | 规范文字 | 结论块、汇总表、检验章六小节、图后解读段、摘要 move，逐项在位 |
| A4 | 数字一致性 | 正文 ↔ 宏 ↔ 账本三处同一个数；抽查若干条能否回读到结果文件 |
| A5 | 证书措辞匹配 | `resolved=false` 的结论有没有降精度；机会约束数字旁有没有下界值 |
| A6 | 图文对应 | 图注与正文说的是不是同一件事；引用编号、图序、表序对得上 |
| A7 | 越级主张 | 最优 / 证明 / 显著 / 必然 / 全局 逐处查，超出证据即标出 |
| A8 | 赛制合规 | 页数口径、匿名、AI 声明、命名、附录指路句 |
| A9 | 复现声明属实 | 论文里写的复现方式与交付包里真能跑的是否一致 |
| A10 | 未决项交代 | 降级声明、未分辨结论、放弃的加分项有没有在文中如实交代 |

**交出**：逐条给**证据位置**的复核意见（文件:行号／页码／账本键）。只写「已核对」「无问题」的条目视为未核。

---

## Finisher

编译、合规、打包。机械但要一次做对——这一步出错，前面全白做。

| # | 维度 | 验收 |
|---|---|---|
| F1 | 编译零阻断 | 按锁定的模板与引擎编译；`latex_gate.py` 阻断项清零 |
| F2 | 页数切分 | 正文与附录按 label 程序化切分，两侧上下限分别达标 |
| F3 | 清理清单 | 缓存、字节码、测试缓存、LaTeX 中间产物，交付包内为零 |
| F4 | 出门扫描 | `pkg_scan.py` 退出码 0；凭据必须换成环境变量而不只是删字符串 |
| F5 | 复现入口 | 入口脚本复制进交付根并填了真实重算命令；只跑只读检查不算通过 |
| F6 | manifest | 逐文件相对路径 + SHA-256 + 生成命令，与包内比对 |
| F7 | 解包抽查 | 压缩后解压，在解包目录里真跑一次入口脚本 |

**交出**：交付包 + 各 Gate 记录（命令、退出码、判定、证据路径）。
