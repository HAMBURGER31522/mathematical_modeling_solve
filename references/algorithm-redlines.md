# 算法红线：七条通用不变量与实测反例

来源：对 5 个开源建模 skill 各做 2 轮全流程实测（同一竞赛题、两种模型跑题、盲评对照 24/25 分基线），10 次运行全部未过算法门禁。败因收敛成以下与算法无关的不变量。

**总则：红线是终止条件，不是披露条件。** 发现违反必须修复或按规定降级，"已在论文如实披露"不构成豁免（实测三次翻车正是"论文自认下界不达标、照样把它当答案交了"）。判定标准以本文件为准，通过标准以 SKILL.md 各 Gate 为准，冲突时取更严者。

## R1 题面口径忠实（fail，不可豁免）

**判定**：
- 判据、约束、边界规则、实体独立性、对象精确定义按题面原文实现；任何简化必须给误差上界 + 定量对照实验证明不翻转结论 + 论文披露。近似导致结论翻转（含"关键数值差 ≥ 题面精度"）即禁用近似。
- **近似先标定再使用（实测反例：capsule 近似偏差 1.2% > Δ=0.01% 却只检查导通结论不翻转就放行，阈值被系统性推低 5 根）**：任何几何/数值近似（capsule、内接球、离散化、线性化）在进主计算前，必须在标定样本（≥100 例覆盖正常+退化+边界构型）上与精确方法逐例做差，记录 max|bias| 并与 Δ 比较。**判定不是"导通结论是否翻转"，而是"任何关键中间数值（概率/根数/成本/阈值）偏移是否 ≥ Δ"**--中间值偏移 ≥ Δ 即禁用该近似，必须换精确实现或加偏差修正。标定结果写 `结果/近似标定.md`（近似名、标定样本量、max|bias|、Δ、结论：可用/禁用/修正）。G3 查此文件，缺 = 近似未标定 = R1 fail。只承认近似是缺点但不量化影响 = 不构成标定。
- **跨问一致**：同一交付物内各问口径必须一致，一致性以代码取证（共享内核 + 行号抽查），不以论文声明取证；确需分叉的要有题面依据。
- **禁私货约束**：模型每条约束能指到题面原文；"两种资源都要用""变量必须为正"这类直觉先验指不到原文即 fail；端点/退化方案必须显式评估而非默认排除。
- 本条证据来源包括合理性检查（computation-standards §7）——量级荒谬的结果优先怀疑口径/实现而非模型。

**实测反例**：边界截断实现成"整体不得出界"的拒绝采样（阈值系统性偏高 2 倍，恰落在基线定量证伪过的口径预测值上）；电极面判定退化使越界实体同时短接两极（四问数值全废，概率全 100%、成本差 96 倍）；胶囊近似产生假阳性接触边（误差与效应量同量级的系统偏差）；Q1 与 Q2–Q4 各用一套互斥口径全程未察觉；自加"两材料都 ≥1"排除真实最优解。

## R2 家族匹配证书 + 选择认证分离 + 达标（fail，不可豁免）

**判定**：证书类型必须与 P2 登记的方法家族匹配，禁止跨家族套用：

| 家族 | 匹配的证书 |
|---|---|
| M1 随机仿真/机会约束 | 预先声明的单侧置信下界（如 Wilson 95%）≥ 阈值；选择与认证分离 |
| M2 精确优化 | 对偶 gap / MIP gap 低于预声明容忍，且解代回原始约束独立验证 |
| M3 启发式 | 下界或基准对比 + 多重启结果分布（只报最好一次 = 樱桃采摘） |
| M4 统计/ML | 区间 + 检验 + 无泄漏的验证划分 + 外推域声明 |
| M5 数值方程/PDE | ≥2 档网格加密的收敛阶 + 守恒量/不变量残差 + 与解析/极限解对照 |
| M6 图论/组合 | 精确算法给最优性论证；近似给近似比或与小实例精确解对照 |
| M7 评价决策 | 权重扰动下排序稳定率 + 换一种评价法结论一致 + 一致性检验不硬凑 |
| 确定性判定（是/否类） | **裕度证书**：判据参数放大/缩小多少倍才翻转结论，配临界样本清单。**翻转参数必须选结论真正敏感的那个**——先验证候选参数确实能翻转结论再报它；若某参数在可行域内怎么变都不翻转（如构型允许重叠时的接触阈值），该参数的裕度恒为 ∞/0，**属空证书不得上报**，须改报真正的敏感参数（几何尺寸、密度、体积分数）或改用瓶颈量（最宽路径的最窄处）。裕度为 ∞ 或 0 时必须书面说明"该参数不敏感"并给出替代参数的数字 |

- **证书计划先行**：认证前写明估计量、适用假设（Wilson/Clopper-Pearson 只适用于独立同分布 Bernoulli；加权/相关/序贯场景须给覆盖率依据）、置信水平、单双侧、同时比较项数 K 与 alpha 分配（Bonferroni：`certify.py --m K`）、样本承诺、失败后唯一动作。
- **一次封存、一次终验**：候选方案封存后用独立种子终验；终验失败只能判不可行或重新进入选择阶段并用全新批次，禁止反复换种子重测（名义覆盖率会失效）。终验样本量按把握度排（`certify.py --solve-n` 的 n_power），不按临界 n 排。
- **达标才算证书**：下界 < 阈值 = 该方案不可行，不得作为答案进 ledger 与论文（点估计贴线同罪）。达标（R2，不可豁免）与已分辨（R5 的 u ≤ Δ/3，可降级）是两级判定，分开记（certify.py 的 pass 与 resolved 字段），不得混为一谈。
- 反向坑：小样本 + 下界门槛 = 过度保守假阴。处置顺序见 computation-standards §5——先提精度在原答案点重判，禁止用抬高答案替代提高精度。

**实测反例**：8/10 次把 p̂≥0.90 点估计当可行证书；同批样本既选方案又发证书（"更优成本"在独立重验下不成立）；400 样本 Wilson 过不了线就把答案抬保守一档，数值输掉一个量级。

## R3 最优性主张分级（降级 = 删改结论，不得保留原措辞）

**判定**：最优性声明分三个互斥等级，措辞与等级严格绑定：
- `global_certified`：完整可行域穷举、有效全局下界/对偶界、或可证明的分支剪枝。才可写"全局最优"。
- `local_certified`：最优点邻域（整数邻域逐点核查 + 多重比较校正）排除。只可写"在明确邻域 N 内最优"。**邻域排除不支持全局最优主张。**
- `best_found`：只可写"在已搜索集合 S 内未发现更优，S 定义为…"。启发式 + 基线对比属于此级。

统计排除必须给同时置信保证（Bonferroni 或联合置信带，否则族错误率失控）。

**下界构造清单（按可用性排序）**：① 松弛/对偶下界；② 单调性 + 端点认证覆盖整段；③ 逐点统计排除 + 多重比较校正；④ 分辨率论证（未测点与已测点目标差 < 已认证最优间隙）；⑤ 决策空间允许时直接穷举。报告最优性必须写清"排除到什么粒度、未排除区域、残余间隙"。

**实测反例**：多家 4–7 个网格点扫描后宣称"全局最优"。

## R4 核心原语神谕独立单测（fail，不可豁免）

**判定**：
- expected 来自手算、解析几何、或另一独立算法（暴力点云、符号计算、极小规模精确求解），**禁止 expected 由被测函数或其换壳版本自产**——同源即本条 fail。
- 退化清单按原语类型选：距离/相交类（零长、平行、共面、相切、端点落界、空集、单元素）；连通/可行类（空图、单点贯通、全满贯通、自环）；目标函数（全零决策、约束边界点、不可行点必须报不可行）。
- 语义验收测试（P1 产出）作为黑盒层：期望值来自题面原文，不来自 PLAN 的"采用口径"，防止同一误解污染实现与测试。
- 必测回归用例：杆 (0,0,0)-(10,0,0)，球心 (5,1,0)——球到杆的距离应为轴距 1，不得退化为到端点的 5.099（实测零长线段退化 bug 使整问报废，5 行单测即可拦截）。

## R5 分辨率预算对齐 Δ（降级 = 降精度报告，不得报满精度）

**判定**：
- **Δ 的来源受限**（按优先级，禁止自拟宽松 Δ）：① 题面明确精度（"精确到百分号下两位"→ Δ 由此倒推）；② 待比较方案目标差的 1/3；③ 决策变量最小可分辨单位（1 根、1 个、1 格）。
- 认证不确定度 u ≤ Δ/3（机会约束场景 u = p̂ 与单侧认证下界之差，certify.py `--delta` 自动判；其他场景 u 为置信半宽/SE/gap）；误差预算表（depth-review 第三问）逐项与 Δ 对账。
- 下界过线但 u > Δ/3：证书有效但"未分辨"，结论降到题面精度的下一档或加算力，禁止报满精度答案。假阳（预算不足硬报）与假阴（过度保守）都算违反。
- 预算不足的优先序：换高效估计量（充分统计量/增量算法一次出全曲线 + 天然共同随机数）> 方差缩减/配对 > 内核加速 > 并行 > 降样本并同步降级结论。禁止静默砍采样。

**实测反例**：10/10 采样 200–3000 次 vs 基线 4–6 万；把 Δ 自拟成"5 个百分点"让 n=400 显得合法而题面要求 0.01%。

## R6 数字单向流 + 复现可达（fail，不可豁免）

**判定**：
- 数字流向唯一：代码 → `results_ledger.json`（source 必填：script+params+file+field，schema 见 computation-standards §7，`ledger.py --validate` 机检）→ 论文（`ledger.py --emit-tex` 宏注入）。禁止手抄。
- **stale 传播**：ledger 每条记录带 `depends_on`（内核模块/输入文件），入账后 `ledger.py --freeze` 记 SHA-256；依赖变更后 `--stale-check --write` 标 stale，stale 键不得回填论文，论文引用 stale 键 = fail。
- **三向审计**：`audit_numbers.py` 从 source.file+field 回读复算——论文数字 ↔ ledger ↔ 磁盘结果文件逐条比对（值、单位、区间、样本量都对上）；回读不了 = 三向退化成两向 = fail，不接受"人工核对过了"。
- **数字→脚本可达**：ledger 每条的 source.script 必须在交付包内且能被 run_all 调用路径到达；"论文有数、包里没有生成它的代码" = fail。交付包自含（不依赖包外绝对路径），汇总文件分问命名防覆盖。

**实测正反例**：数字冻结/三向审计是实测唯一被验证真实有效的候选机制（逐位吻合），直接萃取；但多家复现链断裂（驱动脚本未随附、run_all 与最终数字对不上、汇总文件被最后一次单问运行冲掉）。

## R7 赛制合规（阻断提交）

**判定**：见 compliance.md 检查单。AI 使用声明、文件命名、匿名性属"一票取消评奖资格"级，作为打包前阻断性门禁。实测多家漏 AI 声明、文件名不合规、占位队号未替换。

## §locator：题面原文定位写法

口径决策表与私货约束扫描里的"题面原文引用"必须可复核，统一写法：
- 题目 PDF：`题目.pdf p.3 §问题二` 或 `p.2 图1 注记`；关键口径把原文句子摘录（或裁剪图）存 `结果/证据/A<编号>.md|.png`。
- 数据附件：`附件1.xlsx#Sheet1!B2:D400` 或 `附件2.csv 列"直径"`。
- 章程/规范：`格式规范.pdf p.1 第X条`。
只写"题面说了"不给 locator = 该点未审定。

## 与深度审查的关系

红线是判定；depth-review.md 的五问是产生判定证据的流程。对应：R1 ← 口径决策表 + 外部核验（声明-实现抽查/跨问一致/私货扫描）；R2 ← 声明强度分层 + M1.6；R3 ← gap 审计；R5 ← 误差预算表；R4/R6 由 P3 工件直接判。

## 搜索网格的分辨率红线（2026-09-03 实测教训）

**网格步长由可行前沿的陡度决定，不是预设的等距刻度。**

两家独立候选在同一道题上栽在同一处：最优点落在网格缝里，被整个跨了过去。

| 候选 | 决策变量网格 | 真最优点 | 它报的答案 | 代价 |
|---|---|---|---|---|
| A 家 | 0,100,…,500,550,600,650 | 615 | (600,225) 混合方案 9.283 元 | 劣 1.7% |
| B 家 | …,500,600,800,1000,1200 | 615 | 落在 600 与 800 之间 | 同类 |

`(600,0)` 的可行概率 0.8658 不达标、下一格 `(650,0)` 又太贵——真正的可行最优 615 根本没被评估过。
**这不是算错，是搜索空间的构造性遗漏，算法门禁一样判负。**

**必须做到（缺一即 R5 不通过）：**

1. **前沿附近退化为单位步长**：先用粗网格定位可行/不可行的分界带，再在分界带内以决策变量的自然单位（整数根数、整数个数）逐点扫。
2. **把别问解出的阈值点强制塞进候选集**：本题 Q3 已解出阈值根数，Q4 的候选集里就必须包含它及其邻域 ±3。
   跨问的已知解是最廉价的高价值候选，漏掉它等于自废武功。
3. **边界点必须在网格里**：纯 A（另一介质为 0）、纯 B 这类退化方案是天然候选，网格必须显式包含。
4. **报告时给出网格与最优点的关系**：最优点是否落在网格点上、相邻网格间距是否小于最优点到可行边界的距离。
   答不上来，"最优"两个字就不能写。

## 每问都要「写出模型、讲清算法」（2026-09-04，来自真实评委反馈）

同题交付物拿到的两条扣分意见：

> **问题一未介绍使用的算法。**
> **问题三未建立优化模型。**

这两条都不是算错，是**该写的没写**——但在评审里与算错同样扣分。

### R8 每问必须有可见的「算法」段落

- 每问的求解部分必须有**独立可见的算法介绍**：输入 → 步骤 → 输出 → 复杂度。
  用 `algorithm` / `algorithmic` 环境的伪代码最佳；无宏包时用编号步骤列表，但**不能只有一段散文**。
- 摘要里出现的算法名，正文必须有对应的算法段落。摘要写了「并查集」而正文没讲怎么建图、
  怎么并、怎么判同根，就是「未介绍算法」。
- 判据：**把正文的算法段落交给一个没读过代码的人，他能不能重写出这个算法。**
- 检查动作：逐问搜索「算法」「步骤」「伪代码」「复杂度」四个词，四问都要命中。

### R9 每问都要写成形式化模型（含反解/阈值类问题）

- 阈值反解、参数标定这类问题**同样要形式化为优化模型**，不能只报一次扫描结果：
  `min φ  s.t.  P(导通 | φ) ≥ 0.90`，再说明用什么方法求解这个模型（扫描 + 证书、拟合反解、二分等）。
- 只给「扫了一遍网格，取第一个达标点」＝ 评委眼里的「未建立优化模型」，即使数值完全正确。
- 判据：每问是否能指出**决策变量、目标函数（或判定准则）、约束**三要素。缺任一即不合格。

### R10 从数据反推的结论必须做排他性检验

评审原文：

> **问题一对微构体检验有误，YZ 坐标落在 [-55,55] 内与边长 10000nm 正方体并不冲突。**

这是一次**推断的逻辑漏洞**：观察到某个坐标范围，就断言它与某尺寸假设矛盾——
但该观察在另一种假设下同样成立，因此推不出矛盾。

- 任何「由数据反推出 X」的结论，必须回答：**这个观察在 not-X 的情况下会不会同样出现？**
  答「会」就说明这不是证据，只是相容。
- 反推类结论要给**排他性论证**：列出被排除的替代解释，并说明各自被什么观察排除。
- 与「事实／假设／推断三分清单」联动：**推断类条目必须附排他性检验**，否则降级为假设。

### R11 临界方案必须独立复核

评审建议：

> **强化临界方案的独立复核。**

- 最优解、阈值点、可行边界上的方案，**必须用与主管线独立的第二实现复核**
  （不同实现、不同随机流、不同判据路径），而不是用同一套代码换个种子再跑一遍。
- 复核不一致时，写清哪条可信及理由（残差诊断／方向性论证），不得取平均含糊过去。

## 退化规模检验：一条能在 30 秒内救命的检查（2026-09-04 实测事故）

### 事故经过

一次用本 skill 完整跑通的交付物：**50 页论文、92 项测试全过、G0–G7 全绿、降级声明诚实**，
四问答案却错了近 70 倍——Q3 报最小根数 `9`，真值 `615`。

根因只有一行代码：生成的每根圆柱被折回规则切成多个碎片后，**这些碎片被当成同一个电节点**
（`Entity("A", wrap_cylinder(raw))`）。于是一根跨越边界的柱子同时出现在左右两侧，
**它自己就把两个电极短接了**。

实测：`单根柱子独自导通 = 25.2%`（400 次抽样）。而一根 5000 nm 的柱子横跨 10000 nm 的两极，
物理上不可能。$1-(1-0.252)^9 = 92.4\%$ —— 与它报告的 Q3 证书 `92.4625%` 严丝合缝。

**门禁为什么没拦住**：附件复现检验（组1/2/3 = 2/27/165 边）**通过了**——因为附件每行本来就是独立碎片，
不经过折回逻辑。**那条检验只验证判定层，完全没有覆盖生成层。**

### R12 折回／镜像碎片不得跨电极短接

题面声明某些面绝缘时，**折回产生的碎片是彼此独立的实体**，不得共享电节点。
节点定义、边定义、电极接触判定必须用同一套身份口径（见 computation-standards 的「被切分个体的物理身份」）。
违反即 fail，不可豁免——历史上两次栽在这同一处。

### R13 退化规模检验（成本近零，杀伤力最大）

**把规模参数降到物理上不可能成立的值，检查结果是不是不可能值。**

| 检验 | 期望 | 违反说明 |
|---|---|---|
| 个体数 = 1 | 若单个个体在几何上不可能连通两端，导通率必须恒为 **0** | 单体自导通 = 存在短路通道（折回短接、镜像泄漏、判据尺度错误） |
| 个体数 = 0 | 一切"存在性"结论必须为假 | 空构型出结论 = 图/并查集初始化有幽灵节点 |
| 判据阈值 → 0 | 连接数应趋于最小（通常仅剩重叠） | 阈值归零仍大量连边 = 距离函数符号或量纲错 |
| 判据阈值 → 很大 | 连接数应趋于全连通 | 不单调 = 判据实现有分支错误 |

**每问进入生产批之前必须跑完这张表并落盘**。它比任何统计证书都便宜，却能拦住统计证书拦不住的错误——
上面那次事故里，`n=1` 这一行只要跑过，30 秒就能发现。

### R14 题面给定的参数档位是量级标尺

题目让你算哪几档，那几档就是答案应落的量级。

- 本题四档为 0.5%–1.0%，而事故交付物求得的阈值对应体积分数约 **0.013%**，比最小档低了一个半数量级。
  **题目不会让你在它给定的档位之外一个数量级处找答案**——出现这种情况先查口径，不要先信自己的数。
- 判据：把最终答案换算到与题面档位同一量纲，比较量级。差 ≥1 个数量级即触发口径回查，写进 G3 记录。

### R15 多档结果必须可分辨

题目要求算多档，就是预期各档**不同**。

- **多档结果全部相同（尤其全部饱和到 100% 或全部为 0）＝ 口径错误的强信号，直接 fail。**
- **不要把它当成样本量不足去自动扩容**——事故交付物正是把"四档均 k=500/n=500"当成已认证的可行结果，
  还给出了漂亮的 Bonferroni 联合下界 99.0052%。样本量再大也救不了错的物理。
- 判据：相邻档的点估计之差是否显著大于各自的区间半宽。全档无差异即回查口径。
