# 深度审查：五问五工件 + 方法家族模块

对每问在写论文前跑一遍；全文完成后对最终声明再跑一遍强度校准（P6 自审第三轮）。有效性来自**强制中间工件**——工件表必须真实产出并落盘 `结果/审查/`，且**表中"量级""与 Δ 的比"必须是数字，填形容词（"小""可忽略""不适用"）= 该行 FAIL**。

## 审查深度分级

- 承载最终答案且有争议/近似/随机性的问：跑完整五问。
- 结论为确定性判定且已有裕度证书的问：可只跑第一问 + 第五问 + 声明-实现一致性抽查，裁剪理由写 `结果/审查/裁剪说明.md`。**被裁剪的项不得是该问的主要风险来源。**
- 每问工件可合并为一份 `结果/审查/qN.md`（分层表、gap、误差预算、赏金、diff 五节），不必五个文件。

## 前提

读懂求解机制本身：估计量/目标函数/判据如何定义、随机性或近似在哪引入、结论数字从哪个中间量算出。只看结论不看机制的审查无效。同时完成方法家族识别（M1–M7，可多挂）。

## 第一问：声明强度分层表

逐条结论填"声称等级 / 实际达到等级 / 差距"：

| 等级 | 含义 |
|---|---|
| S1 数学证明 | 有严格证明的最优性/正确性 |
| S2 确定性界 | 有可计算的 gap（上界−下界），gap 已量化 |
| S3 统计证据 | 置信区间/假设检验支撑，噪声水平已报告 |
| S4 经验无保证 | 收敛曲线好看、多次运行一致，但无任何界 |

S1–S4 是**证据类型**而非绝对排名（正确覆盖的 S3 不必然劣于与问题不匹配的 S2）；另判"该主张是否被该证据充分支持"PASS/FAIL。声称等级高于实际等级的表述必须降级改写；S3 证据禁用 S1 措辞。

## 第二问：gap 审计（上界−下界框架）

现有解是上界，"不可能更好"需要下界。下界从哪来（对偶/松弛/统计排除/穷举/理论界）？两端各自多硬？**没有下界是头号发现**——最优表述立即按 R3 三级（global_certified / local_certified / best_found）降级，并评估补下界的成本。下界构造清单见 algorithm-redlines R3。

## 第三问：误差预算表

| 误差源 | 是否存在 | 量级（数字） | 与 Δ 的比（数字） |
|---|---|---|---|
| 统计噪声（有限样本） | | | |
| 离散化/网格/步长 | | | |
| 模型近似（几何简化、线性化、代理模型） | | | |
| 数据不确定性/参数标定 | | | |
| 优化 gap（局部最优、早停） | | | |
| 实现偏差（代码与论文口径不符） | | | |

任何一项 ≳ Δ，相关结论不成立。注意：系统性偏差（模型近似）不随样本量消失——它与争论中的效应量同量级时，哪怕远小于统计噪声也必须修。

## 第四问：悬案赏金表

| 悬案 | 效应量 Δ（解决它值多少） | 当前分辨能力 | 所需投入 | 赏金/成本比 |
|---|---|---|---|---|

按比排序定改进优先级；"花钱买不到结论"的项写"放弃，投入取 0"并给算术依据。

## 第五问：工具箱 diff

按家族逐项标"已用/未用/不适用+理由"。前半判断结构是否已最优，后半是常见推断/实现漏洞。只列适用项，不必复制整套清单。

### M1 仿真 / 蒙特卡洛 / 随机优化
1. 充分统计量/条件蒙卡（一次仿真重构整条曲线；有单调/嵌套结构时默认必用，"不适用"须证明结构不存在）
2. 共同随机数与配对设计（比较方案时差值统计量方差最小化）
3. 单调性等结构利用（剪枝、嵌套扫描、支配点）
4. 方差缩减（分层、控制变量、对偶变量、重要性抽样）
5. 序贯检验（SPRT / anytime-valid）
6. **选择与认证分离**（同批样本既选又证 = 选择偏倚；实测两轮各一家栽在这条）
7. 多重比较校正（格点扫描的族错误率）

### M2 精确优化（LP / MIP / 凸优化）
1. 对偶/MIP gap 报告且收敛；2. 松弛质量（割平面/有效不等式）；3. 对称破除、预处理、warm start；4. 解代回原始约束独立验证；5. big-M 松紧、线性化误差；6. 规模-复杂度匹配（本可精确就别近似）。

### M3 启发式 / 元启发式
1. **有没有任何下界或基准**——最常见致命缺失；2. 多重启分布（只报最好 = 樱桃采摘）；3. 参数敏感性与停止准则；4. 已知最优小实例校准；5. 规模允许时启发式是降级选择。

### M4 统计 / 回归 / ML
1. 数据泄漏与验证划分（时序前向验证）；2. 可识别性与共线性；3. 过拟合控制；4. 点估计配区间；5. 外推域声明；6. 选择后推断偏倚。

### M5 数值微分方程 / PDE
1. ≥2 档网格加密 + 收敛阶；2. 守恒量核查；3. 刚性与稳定域匹配；4. 与解析/基准/极限解对照；5. 长时间误差累积。

### M6 图论 / 组合 / 网络
1. 复杂度与规模匹配；2. 近似比声明；3. 特殊结构利用；4. 退化与平局处理。

### M7 评价 / 决策类
1. 权重敏感性（扰动看排序翻不翻）；2. 换评价法结论稳健性；3. 一致性检验不硬凑；4. 指标独立性与量纲。

新家族 = 新增 M 模块（工具箱清单 + 常见漏洞清单），核心五问不动。

## v3.2 E/V/A 证据链硬检查

三方评审共同暴露的短板不是“有没有写检验”，而是 E（证据强度）、V（检验广度）、A（算法深度）没有覆盖临界点。对每个承载最终结论的问，审查者必须从 `结果/审查/P3-EVA-证据矩阵.md`、代码和原始结果回读下表，并把复核结果落盘 `结果/审查/EVA-检查表.md`。表中 `artifact`、实际命令/输出与退出码、数字、适用性和判定缺一不可。

| 维度 | 检查项 | 最低证据与数值要求 | 缺失时判定 |
|---|---|---|---|
| E | 三路独立估计路径 | 阈值/相变/机会约束问题用 3 个不同模型族；逐路给点估计、区间、seed、scope、verdict，差异与 Δ 的比值可回读 | 少一路、同代码换 seed 或差异无解释 = FAIL |
| E | 外部理论量级（Balberg） | 适用随机几何/渗流时给 Balberg 型关系的出处、公式、假设和代入数字；否则给有出处的同领域理论界/尺度律 | 只有“符合理论”或没有量级代入 = FAIL |
| E | 解析算例与暴力对照 | 至少 3 个可手算解析算例；独立暴力/枚举/点云 oracle 给方向性断言，不得调用生产判据自产 expected | 少于 3 个、同源或只有“接近” = FAIL |
| E | 误差传导 | 配对报告中间量偏差、最终答案偏差、偏差**方向**、各自与 Δ 的比；证明实验分辨力足够 | 只报边/概率误差，未报**最终答案偏差** = FAIL |
| E | 多种子临界扫描 | 临界点和相邻整数/网格点至少 3 个独立 seed；每点有 n/k、区间、verdict、resolved、scope | 少于 3 seed 或相邻点 inconclusive 未补样 = FAIL |
| V | 有限尺寸/胞元形状 | 随机几何/场问题至少 3 个尺寸、2 种同体积胞元形状；报告输出差、方向和是否翻转 | 只跑一个尺寸/形状或无量化 = FAIL |
| V | 阈值灵敏度系数 | 写出扰动步长 h、公式/离散替代、单位、数值系数和结论翻转情况 | 只说“对阈值敏感” = FAIL |
| V | 全前沿价格灵敏度 | 沿全部可行前沿给成本—性能数字，并扰动所有价格系数；不能只测被选点 | 只有最优点成本或缺价格扰动 = FAIL |
| A | 上下界夹逼偏差方向 | 证明 `L≤真值≤U`（或题目对应方向），报告有限迭代/采样/松弛的偏差方向与 gap | 只列上下界数字，没有方向证明 = FAIL |
| A | 单位步长整数前沿 | 粗网格后在自然单位逐点扫，最终点 ±1（必要时 ±2）单独认证，排除所有更低成本候选 | 网格跨过临界点或邻点未认证 = FAIL |
| A | 病态切换记录 | 记录条件数/残差/边界触发值、切换前后算法、重算数字和降级措辞 | 静默切近似或只在代码里留分支 = FAIL |
| A | 细长胞元结构反推 | 对细长胞元等替代结构做可生成性、量级和排他性检验；排不掉的只写“与观察相容” | 由坐标范围直接断言结构，未排除替代解释 = FAIL |

**统一判定规则**：缺少工件或数字 = FAIL；只写“已检查”“不适用”“影响很小”而没有适用性判据和量化理由 = FAIL；不同路径结果不一致时不能取平均或择优。对资源不足的项，必须保留实际样本量、分辨力、未决风险与降级措辞，不能把缺项改成 PASS。该表是 P4 的独立检查，不因 P3 自报完成或论文已有一段描述而豁免。

### Canonical schema 与官方门禁

P3 的 结果/审查/P3-EVA-证据矩阵.md 与 P4 的 结果/审查/EVA-检查表.md 必须使用同一 canonical 表头，并各含 E1-E5、V1-V3、A1-A4 一行：

```text
| id | dimension | criterion | artifact | command | exit_code | numbers | applicability | verdict |
```

审查者先从工件、命令输出和源码回读每一行，再运行：

```bash
python scripts/eva_gate.py 结果/审查/P3-EVA-证据矩阵.md --review 结果/审查/EVA-检查表.md --root . --out 结果/gates/EVA.md
```

该脚本只放行交付契约完整且所有适用项为 PASS 的两份矩阵；它不能证明理论或数值科学正确性。退出码非 0、工件缺失、命令退出码不是整数、数字缺失、N/A 没有定量理由，均保持 G4 FAIL。

## 兜底元规则

- 假设结论是错的，最可能错在哪一步？
- 最强反对者会攻哪一点？写出攻击并正面回应。
- 声明-实现一致性、跨问一致性、量级对照——这三条已升级为 G4 必产工件（外部核验，见 SKILL.md P4），不再只是兜底。

## 改进建议输出（四箱 + 放弃项）

- **结构性**（换估计量/算法/松弛）——前半工具箱全"已用"时此箱为空，明说
- **推断性**（序贯、方差缩减、认证分离、gap 收紧、收敛性补做）
- **工程性**（内核提速、并行、缓存）
- **表述性**（措辞升降到实际强度等级）
- **不建议做的事项及理由**（赏金表买不到结论的项，逐条算术依据）

输出顺序：总评一段 → 分层表 → gap 审计 → 误差预算 → 赏金表 → 工具箱 diff → 四箱 + 放弃项 → 优先级一句话。

## 填表标定样例（合格 vs 不合格）

某随机几何优化问（M1）的三行示范——**只作填表标定，不是题解**：
- 误差预算合格行："模型近似（胶囊代平底柱）| 存在 | 阈值偏差 ≈ 0.01 个百分点 | ≈ 1.0×Δ（题面精度 0.01%）→ 必须修"。不合格行："模型近似 | 存在 | 量级小 | ≪ 1"（无数字，FAIL）。
- 分层表合格行："'满足 ≥90% 约束' | 声称 S2 | 实际 S3（Wilson 下界 0.9002，n=60000）| 差距：无，措辞改'95% 置信下界满足'"。不合格：下界 0.8895 < 0.90 仍标"满足约束"。
- 赏金表合格行："纯 A 方案 614 vs 615 之争 | Δ≈0.16% 成本 | 当前不可分辨 | 需 ~66 万路径 ≈ 150 机时 | 比值低 → 放弃，投入取 0"。

## 误差必须传导到结论量（2026-09-03 从标杆交付物萃取）

**中间量误差小 ≠ 结论误差小。** 临界系统会放大少量结构性偏差。

标杆交付物里这一段是全文最有说服力的地方，它的做法值得照搬：

1. 先统计中间量误差：近似判据导致的边剔除率 1.38%–1.50%。
2. **然后自己否定这个证据**："此前只统计了边的误判比例，并以『四档各 30 次构型中导通结论零次改变』佐证其可忽略。
   这一推断是错的：该实验没有分辨力"——30 次构型在 1.5% 的真实翻转率下根本测不出差别。
3. 改用**有分辨力的配对实验**：2 万条逐路径配对，测得精确判据使首次贯通平均晚 5.70 根、
   90% 分位由 606 移到 613、阈值由 0.8567% 移到 0.8666%，**最终改写了报告精度 0.86% → 0.87%**。

**硬条件：**

- 任何"该近似/误差可忽略"的声称，必须**同时报告中间量误差与最终目标量误差**。只报前者视为未论证。
- 用来支撑"可忽略"的实验必须先算**分辨力**：实验能分辨的最小效应量是否小于所声称的效应量。
  分辨力不足的零结果不是证据，是没测出来。
- 误差要给**方向**（系统性偏高还是偏低），不能只给绝对值。
- 结论：给出误差是否改变了报告精度/最终答案，而不是停在"影响很小"。
