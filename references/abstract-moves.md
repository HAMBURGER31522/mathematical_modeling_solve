# 摘要 move 库

> 触发条件：写摘要或改摘要之前读。
> 这是从 12 篇国奖论文摘要里对齐出来的**不变项与可变槽位**：
> 几乎所有范文都做的动作是骨架，其余是槽位。语料出处见 `ATTRIBUTION.md`。

---

## 0. 跨篇统计（蒸馏依据）

共 12 篇摘要（11 截图 + 1 PDF）。 shorthand：[多波束] [定日镜场] [黄河水沙] [农作物] [深弹] [交通] [烟幕] [碳化硅] [NIPT] [矿井] [姿态] [微构体]。

| 观察项 | 频次 | 说明 |
|---|---|---|
| 「针对问题N／对于问题N」段首标记 | 12/12 | 全部一问一段，无例外 |
| 段首标记加粗 | 8/12 | [定日镜场][烟幕][NIPT][交通][微构体] 等加粗，[多波束] 等不加粗 |
| 方法/模型名加粗 | 11/12 | **[微构体] 是反例：方法名（Wilson/Logistic/蒙特卡洛）全不加粗**，只加粗段首标记与结果 |
| 关键结论 + 数字加粗 | 12/12 | 全部至少在结果位置加粗；[交通] 问题二 50.35km/h 漏加，属该篇纪律不齐 |
| 总起段（背景+全文路线） | 10/12 | [微构体] 仅一句「本文以连续渗流与图连通性刻画之」，极简变体 |
| 段内含验证/稳健性句 | 8/12 | 双算法互证、灵敏度分析、多维度检验 |
| 摘要内嵌数据表 | 1/12 | [黄河水沙]（2016–2021 逐年总量表） |
| 摘要内指图/指附件 | 5/12 | 「详见图 12 和图 13」「见附件 result1.xlsx」「对照见 6.2 节」 |
| 结尾创新点段 | 1/12 | [NIPT]「一是…二是…三是…」 |
| 关键词行 | 12/12 | 4–6 个，含方法词 |

**每问一段篇幅**：3–10 句；总摘要约 0.8–1.2 页。没有一篇是"每问一句"。

**加粗密度逐块复核**——"块" = 连续加粗串，逐段重数其中 4 篇：

| 篇目 | 各问段加粗块数 | 风格 |
|---|---|---|
| [微构体] | 2 / 2 / 3 / 2 | 最稀疏：段首标记＋结果数字，**方法名一律不加粗** |
| [多波束] | 1 / 0 / 2 / 5 | 稀疏：多数问 1–2 块，仅方法最密的问题四到 5 |
| [定日镜场] | 3 / 7 / 2 | 语料最密：要素标签＋两个方法名＋结果长串全加 |
| [烟幕] | 3 / 6 / 3 / 5 / 3 | 较密：证明结论/方法名/结果都加 |
| 其余 8 篇 | 未逐块复核（初读印象 2–4） | 中间档 |

结论：语料在稀疏—较密之间自由波动，**不存在统一密度；可蒸馏的是加粗的对象类别（§3），不是数量**。我方规范取稀疏端。

## 1. 摘要总骨架（不变项）

```text
[总起段] 背景/重要性 1–2 句 + 「本文通过/基于XX，建立XX模型，研究/设计XX」全文路线一句
[每问一段] × N问，段首「针对问题N：」
[收尾段]（可选）综上所述… / 本文创新性在于：一是…二是…三是…
[关键词行] 4–6 个，最后一个通常是核心方法词
```

## 2. 每问一段的段内骨架（本蒸馏核心）

固定五动作，顺序不变，槽位可伸缩（简单问可合并，复杂问可 10 句）：

```text
① 段首定位   针对问题N：本问是XX问题 / 在XX条件下，设计XX使得XX
② 建模主张   本文 建立/构建/提出 「**模型名/优化模型**」（加粗）
③ 方法链条   首先/随后/通过/采用/引入 **方法A**（加粗）→ **方法B**（加粗）→ …
④ 结果句     求解得/结果显示 **关键结论与数字**（加粗，结论整句或数字部分加粗）
⑤ 验证句     灵敏度分析 / 第二算法互证 / 多维度检验 + **稳健性结论**（常加粗）
```

用户点名的核心模式（每篇范文逐字可见）：

> 「针对问题一，本文**建立了定日镜场的效率计算模型**」——方法/模型主张加粗；
> 「**年平均输出光学效率 0.536230167、年平均输出热功率 32.76117051MW…**」——结论与数字加粗。

## 3. 加重规则（什么加粗、什么永不加粗）

### 3.1 我方规范：每问一段只加粗三类，各至多一处

规范口径（用户拍板 2026-09-06）：**「建立XX模型」加粗、「用XX算法」加粗、「得出XXX」加粗——除此之外一律不加粗。**

| 类 | 落在哪个动作 | 加粗对象 | 语料例（出处） |
|---|---|---|---|
| ① 建模主张 | 建模句 | 「建立/构建/提出**XX模型**」的模型名或主张短语 | **建立了定日镜场的效率计算模型**[定日镜场]；**构建双光束干涉模型**[碳化硅]；**以…四个参数为决策变量，最大化有效遮蔽时间**的优化模型[烟幕] |
| ② 方法名 | 方法链句 | 本段核心方法/算法名（每段至多 1–2 个，写「中文名（英文，缩写）」） | **二分查找法**[烟幕]；**峰窝排列法**、**蒙特卡洛模拟法**[定日镜场]；**基于差分进化的改进遗传算法（DEGA）**[农作物] |
| ③ 结论与数字 | 结果句 | 最终答案数字/关键结论/编号结论清单（可整句连加粗） | **7.59%、21.27%、47.15% 与 99.33%**[微构体]；**(1) 铺满巷道时间为 1672.06min；(2) …5016.18min；(3) …50161.80min**[矿井]；**覆盖率高达 99.96%，测线总长度为 434662m**[多波束] |
| （可选）段首标记 | 段首 | 「针对问题N：」 | 8/12 篇加粗 |

三类齐全的一段 = **3 处加粗**（该问无独立方法名时 2 处），段首标记另计可选——这就是每问一段的加粗预算上限。[微构体] 走得更省：只加粗段首标记＋结果，①② 全不加重，同样合规。

**语料里有、但我方规范排除的加粗对象**（有先例、不入规范，防止回到密加粗）：
- 模型要素标签「**决策变量**/**约束条件**/**目标函数**」——仅[定日镜场]一家，属该篇风格；
- 比较性发现句「**显著高于…**」「**说明我们的算法能有效求解…**」——[农作物][烟幕]先例；仅当它是该问唯一结论时并入③，不单开一处；
- 证明性结论长句[烟幕问题一]——同理并入③。

### 3.2 永不加粗（12 篇零反例）

过程叙述（首先/其次/然后/最后/接下来）、数据来源（附件2/临床数据）、背景常识、中间推导步骤、未被问题引用的中间量。整体判断标准：**加粗的是"可被评委当作该问贡献/结论捡走的信息块"，其余全是叙述性胶水。**

### 3.3 加粗密度

- 逐块复核（§0 表）：稀疏档 2–3 块/段（[微构体][多波束]），密档 3–7 块/段（[烟幕][定日镜场]）；**语料没有统一密度**。
- 我方规范取稀疏端（[微构体] 所在档）：**每问一段 ≤3 处**（三类各一），全摘要约 8–15 处（4 问）；段首标记可选另计。
- 取稀疏的理由：① 同题获奖范文即如此；② 我方评委反馈是"技术细节略密"，方向一致；③ 密加粗边际信息低、视觉显乱。现行 rule"一句粗体≤2 处"换成"**每问 ≤3 处、三类白名单**"。

## 4. Move 条目（可直接进 skill 的格式）

```markdown
## MOVE-ABS-01 总起段（10/12 篇采用）
- 功能：评委 30 秒内看到全文技术路线与目标
- 槽位：[背景/重要性 1–2 句] + [本文通过/基于**方法词**，建立**模型词**，研究/设计**目标**]
- 正例[NIPT]：「本文基于临床数据，构建了混合效应模型与孕妇潜在风险最小的优化模型相结合的优化框架，系统研究 NIPT 检测时点优化与胎儿染色体异常判定问题。」
- 极简变体[微构体]：「本文以连续渗流与图连通性刻画之。」（赛题已知背景可不复述）
- 反例：复述题面两段才进正题（注水，评委反感，paper/rules 双丢）

## MOVE-ABS-02 段首定位标记（12/12，8/12 加粗）
- 功能：切分器，评委按问扫读
- 槽位：「针对问题N：」或「对于问题N，」+ 一句题型定位（本问是XX问题 / 在XX条件下，设计XX使得XX）
- 正例[微构体]：「针对问题2：本问是随机构型下的概率估计问题。」
- 约束：题型定位优先写"判定/估计/反解/优化/评价"五类范式词，与 skill 题型路由对齐

## MOVE-ABS-03 建模主张句（12/12；加粗类①，每段至多一处）
- 功能：给出该问的可命名贡献
- 槽位：本文 + 建立/构建/提出 + **模型全名**（可含：目标+决策变量的完整刻画）
- 正例[烟幕]：「建立了**以无人机航向、速度、烟幕弹投放、爆炸时间四个参数为决策变量，最大化有效遮蔽时间**的单机单弹情况下的优化模型。」
- 语料动词：建立 / 构建 / 提出 / 引入 / 给出

## MOVE-ABS-04 方法链条句（11/12；加粗类②，每段至多 1–2 个方法名；[微构体]不加重方法名）
- 功能：展示求解路径，方法名可捡走
- 槽位：首先/随后/通过/采用/利用 + **方法A** → **方法B** → …；方法名用「中文名（英文, 缩写）」格式
- 正例[农作物]：「采用**基于差分进化的改进遗传算法（DEGA）**，对滞销和 50%降价出售两种情境进行求解」
- 正例[碳化硅]：「依据 **Snell 定律**修正入射角…利用 **Fresnel 公式**计算…引入 **Cauchy 色散模型**…」
- 约束：每个方法只在其首次出现处加粗；叙述动词不加重

## MOVE-ABS-05 结果句（12/12；加粗类③，唯一全员加粗的位置）
- 功能：该问的最终答案，评委第一眼
- 槽位：求解得/结果显示/最终得到 + **结论与数字**；多结论用 (1)(2)(3) 编号清单
- 正例[矿井]：「得到以下结论：**(1) 铺满巷道时间为 1672.06min；(2) 所有巷道水位高度到达 0.3m 的时间为 5016.18min；(3) 灌满所有巷道的时间为 50161.80min。**」
- 约束：数字必须 ⊆ ledger 达标 authoritative（与现行 audit 规则一致）；精度按题目要求，范文[定日镜场]有给出 9 位全精度先例，但我方按 R5 口径报
- 反例[交通]：50.35km/h 未加粗——纪律不齐，勿学

## MOVE-ABS-06 验证句（8/12）
- 功能：一段话内给该问的可信度证据
- 槽位：灵敏度分析 / 第二算法互证（给相对误差数字）/ 多维度检验 + **稳健结论**
- 正例[烟幕]：「用**粒子群算法**重新求解模型进行验证，发现两个算法的相对误差仅为 0.01%，**说明我们的算法能有效求解本问的优化模型**。」
- 正例[碳化硅]：「从**残差统计特性、正态性检验、角度一致性、系统敏感性**等多个维度对模型进行了可靠性检验，确保了模型的准确性与稳健性。」

## MOVE-ABS-07 口径声明句（1/12，[微构体] 独有高级动作）
- 功能：把最关键的口径选择与反事实代价写进摘要，直接堵住评委最大疑问
- 正例[微构体]：「须强调侧壁口径：题面写明四侧面绝缘不导电，故介质间取真实欧氏距离而不作周期最小镜像；若改按最小镜像允许跨壁搭接，四档将升至 18.5%、46.1%、79.8% 与 100%，约三倍于本文——该口径与题面相悖故不取。」
- 适用：口径存在明显歧义且有翻转风险的题；对应 skill 的 P1 双口径实验结果
- 注意：摘要只放一句浓缩版，完整对照在正文口径决策表

## MOVE-ABS-08 收尾与关键词（关键词 12/12）
- 收尾段（可选）：综上所述…（全文递进叙事）或「本文创新性在于：一是…二是…三是…」[NIPT]
- 关键词：4–6 个 = 问题对象词 + 核心方法词（含缩写）
- 正例[微构体]：「关键词：连续渗流；蒙特卡洛仿真；图连通性；并查集；边界截断口径；成本优化」
```

## 5. 语料动词表（写作时直接取用）

| 动作 | 范文高频动词 |
|---|---|
| 建模主张 | 建立、构建、提出、引入、给出 |
| 方法采用 | 采用、利用、通过、基于、结合、借助 |
| 求解过程 | 求解、求解出、进行迭代计算、反演、拟合、扫描 |
| 结果呈现 | 得到、结果显示、求得、估算出、最终得到、计算得出 |
| 比较结论 | 显著高于/低于、约 X 倍于、优于、相差 X 倍 |
| 验证稳健 | 验证、互证、灵敏度分析、回验、可靠性检验、说明…有效/稳健 |

## 6. 与现行 skill v3.2 规则的差异（需拍板）

| 现行规则（SKILL.md P6） | 12 篇语料显示 | 建议 |
|---|---|---|
| 「摘要每问**一句** = 类型+算法+结论」 | **12/12 都是每问一段**（3–10 句，含过程叙述与验证句） | 升级为"每问一段、五动作骨架"，技术推导仍留正文（两者不矛盾：范文段落里没有推导，只有叙述+结论） |
| 「一句里粗体不超过两处」 | 稀疏档 2–3 处/段，密档 3–7 处/段 | 换成：**三类白名单（模型/方法/结论各一），每问 ≤3 处**；叙述句永不加粗 |
| 「技术细节一律留正文」 | 一致（正文才有公式与表）；例外是结论清单、口径声明可入摘要 | 维持，补充 MOVE-ABS-05/07 两个可入摘要的例外 |
| 摘要指图表未规定 | 5/12 指图/指附件/嵌表 | 允许「详见图 N」与指向 result 附件，不强制 |
