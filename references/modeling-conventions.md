# 建模口径手册

> **本文件回答的是"这道题的数学对象到底是什么"，不是"用什么算法解"。**
> 算法选错还能补救，口径定错则全盘皆错——两次实测翻车与一次真实竞赛评审扣分，全部发生在这一层。
> 配套：`SKILL.md` P1 口径审定（G1）与 P2 拆题选模（G2）；红线 R1／R10／R12–R15。

---

## 0. 为什么口径决策表还不够

已有的做法是：列可解释点 → 给采用口径 + 被否口径 → 做定量对照。
**这一步比较的是"两个口径之间"的差异，全程没有一步是拿口径去撞现实。**

实测：一份交付物完整填了 A1–A9 口径决策表、做了定量反事实对照、G1 通过，
最终答案仍错了近 70 倍——因为它比较的两个口径**都**是错的。

所以口径审定必须多一层：

> **每一条口径决策，都要能回答"如果这条定错了，什么可观测量会不一样"，并把那个观测量真的测出来。**

答不上来的口径决策 = 未审定。这就是 R13 退化规模检验、生成侧对表、量级标尺三条的共同来源。

## 1. 口径四问（每道题都要逐问回答）

### 问一：**对象身份**——什么算"一个东西"？

最容易错、后果最重的一问。当一个物理个体被规则切开、复制、投影之后，**碎片之间还算不算同一个**？

| 候选口径 | 含义 | 后果方向 |
|---|---|---|
| 碎片各自独立 | 同源碎片互不相连 | **漏连**（低估连通性） |
| 同源碎片同一节点 | 同源碎片恒相连 | **过连**（高估连通性）；且极易与另一处判定口径打架 |
| 按物理机理分情形 | 仅当实体上确实连续才相连 | 最贴近物理，但必须给出判定规则 |

**两次真实事故都在这一问上：**

- 一次是"折回碎片保留为同一电节点，却用未折回几何判电极"——**混合口径**，被裁判判方法级 fail。
- 一次是"每个个体的所有折回碎片共享同一节点"——实测**单体自导通 25.2%**，
  一根跨界个体自己就把两端短接了，四问全错。
- 真实竞赛评审也批评过反方向的做法："主动舍弃同源跨界片段的内部连接会造成一定漏边"。

**硬要求**：
1. 显式表态选哪一种，写清题面依据（引原文）。
2. 给**方向性量化**：本口径相对另一口径是漏连还是过连，量级多大（同一批构型做**配对**对照，报边数差与最终答案差）。
3. **全流程同一身份口径**：节点定义、边定义、边界/电极判定必须用同一套，不得一处用折回、另一处用未折回。
4. 用 `scripts/degenerate.py` 撞现实：**单个个体不该连通两端时，`n=1` 的连通率必须为 0**。

### 问二：**边界处理**——越界的部分去哪了？

截断／回绕（周期）／丢弃／反射，四选一，且必须与题面一致。

**关键判别**：题面若声明某些面绝缘或不导电，则**周期回绕在那些方向上不成立**——
回绕产生的碎片是彼此独立的实体，不得共享节点（R12）。

**撞现实的办法**：把判据阈值从 0 拉到极大，连通率必须**看得出变化**。
若毫无变化，说明存在**与阈值无关的短路通道**——通常就是边界处理写错了（`degenerate.py` 的第二个探测器）。

### 问三：**判据定义**——两个对象在什么条件下算"相互作用"？

- 精确判据还是近似判据？**近似只能做预筛，不得当最终裁定**（R-主判据）。
- 近似的偏差**方向**是什么（只多判还是只少判）？上界多大？与效应量 Δ 比是多少？
- 退化情形怎么办：端对端、共线、重叠、零长度、恰好相切。

**撞现实的办法**：解析算例（可手算的特例，≥3 个，报吻合位数）+ 与算法无关的暴力法
（撒点/枚举），且暴力法要给**方向性断言**（"必须永远大于/小于"），不只是"数值接近"。

### 问四：**观测量定义**——最终要报的那个数，到底是什么？

- 是点估计还是概率保证？"满足约束"指均值满足还是以 95% 置信满足？
- 阈值是 `≥` 还是 `>`？取整方向？有效位数？
- 报的是"已认证可行的最小值"还是"扫描到的第一个达标点"？**两者不是同一个东西**，
  措辞必须与 `candidate_scope` 一致（best_found / local_certified / global_certified）。

## 2. 从数据反推结论时的排他性检验（R10）

真实竞赛评审扣分点，值得完整复盘一次。

**场景**：附件三组数据，需判断微构体的真实几何。观察到组1／组2 的 Y、Z 坐标都落在
`[-500, 500]` 内，而 X 跨满 `[-5000, 5000]`。

**当时的写法**（被评审判为"检验有误"）：
> "YZ 坐标落在窄范围内，与边长 10000nm 的立方体矛盾。"

**为什么这是错的**：窄范围与大盒子在形式逻辑上**不冲突**——
一个窄分布完全可能出现在大盒子里，只是概率低。
把"概率证据"直接写成"逻辑矛盾"，中间缺了排除步骤。评审的原话是
"YZ 坐标落在某范围内与边长 10000nm 正方体并不冲突"。

**正确的写法**（同样的结论，补上排除论证）：

1. **精确截断指纹**：组2 的 Y、Z 两端**恰好**取到 −500 与 +500（49 根、98 个端点），
   X 恰好取到 ±5000。随机分布不会让边界值被恰好取到；**取到边界值是"被盒子切过"的指纹**。
2. **物理互斥**：单根柱体积 `π·30²·5000 = 1.414×10⁷ nm³`。
   若组2 真在 `10000³` 立方体内，49 根对应体积分数 **0.069%**，
   比该题的渗流阈值 0.87% 低一个数量级以上，**几乎不可能导通**；
   而组2 **确实导通**（27 条接触边、跨接两端）。
   于是"组2 分布于 10000³ 立方体"这一假设，被它自身的导通事实排除。

**可套用的模板**：

| 步骤 | 内容 |
|---|---|
| 观察 | 我看到了什么（给数字与定位） |
| 候选解释 | 能产生这个观察的**所有**假设，逐条列出 |
| 排除 | 每条候选被什么**独立观测**排除（不能用同一个观察排除它自己） |
| 剩余 | 排除后剩下的解释；若剩不止一条，结论必须降级为"与观察相容"而非"由观察证明" |

**自检问句**（写完每条反推结论后自问）：
**"这个观察在我的结论不成立时，会不会同样出现？"** 答"会"，那它就不是证据，只是相容。

## 3. 题型 → 建模范式路由（P2 用）

方法族（M1 仿真／M2 精确优化／…）说的是**怎么算**；这里说的是**建成什么**。
先认题型，再选方法族。

| 题面长相 | 建模范式 | 核心决策点 | 高频陷阱 |
|---|---|---|---|
| 给定一份具体数据，问"是/否/多少" | **确定性判定**：把数据映射为结构（图／集合／几何体），在结构上求判据 | 对象身份、判据定义 | 用近似判据当最终裁定；数据本身已被预处理过却当成原始 |
| 随机生成构型，问"概率是多少" | **蒙特卡洛 + 区间估计**：生成规则 → 判定 → 计数 → 置信区间 | 生成规则是否忠实题面；样本量能否分辨相邻档 | 生成侧口径与判定侧口径不一致；全档饱和当成样本量不足去扩容 |
| 问"最少/最多需要多少才能达到某概率" | **阈值反解**，且**必须写成优化模型**：`min φ s.t. P(事件\|φ) ≥ α` | 阈值判据用点估计还是置信下界；网格分辨率 | 只报"扫到的第一个达标点"而不写成模型（真实评审因此判"未建立优化模型"）；阈值点的证书跨过阈值时误称"不可行"而非"证据不足" |
| 多种资源、有成本、有性能约束 | **带概率约束的成本优化**：决策变量／目标／约束三要素齐 | 决策变量的自然单位；可行前沿的陡度 | 网格步长把最优点跨过去（三家候选同时栽在这）；把候选集内最优写成全局最优 |
| 给多个方案要排序/打分 | **评价类**：指标体系 + 权重 + 归一化 | 指标定义、量纲处理、权重来源 | 权重拍脑袋且无敏感性分析 |

**跨问一致性**：多问题目几乎总是共用同一套对象与判据。
**四问必须共用同一个判定内核**，各问只在"生成什么、扫描什么、优化什么"上分叉。
四问各写一套实现 = 口径必然漂移（实测：一份交付物 Q1 与 Q2–Q4 各写一套几何，
Q1 正确而 Q2–Q4 全错，因为附件复现只覆盖了 Q1 那一套）。

## 4. 口径审定的出口（G1 增补项）

除原有的口径决策表、定量对照、语义验收测试、清单复盘之外，**必须再落两项**：

1. **每条口径决策挂一个判别实验**：写明"若本条定错，`<可观测量>` 会呈现 `<什么异常>`"，
   并在 P3 把该观测量真的测出来记进 `结果/gates/G3-退化检验.json`。
   挂不上判别实验的口径决策，标 `UNVERIFIABLE` 并在论文披露。
2. **生成侧独立对表**：题面附件的可核事实通常只经过**判定层**，不经过**生成层**。
   必须另设一条生成侧检验——用生成器产出与附件同规模的构型，
   比较碎片数、边数、连通簇规模的分布是否与附件同量级。
   **两层各自对表，缺一层就是裸奔。**
