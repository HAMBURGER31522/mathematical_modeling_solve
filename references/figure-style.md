## 怎么用

在 `开题.md` 的「目标图样例目录」里指一个路径，画图前**把 2–3 张同图式的样例图打开看一眼再动手**。
模仿的是**图式**（版面、色彩编码、轴的处理、图例组织），不是图种，更不是题材——
语料里的火山图、山脊图、UPSet、森林图是生物医学专有的，数模用不上，跳过。

**边界（不可越）**：模仿长相，不模仿数字。图里出现的每个数必须来自 `results_ledger.json`，
样例图的数值一个都不许流进我们的图。

## 「土气 vs 高级」的差在哪

以下每条都来自语料里同一份数据的**普通版与复现版对照**，不是审美偏好。

### 1. 背景与网格：删掉

普通版的灰底 + 白网格（ggplot `theme_grey` / matplotlib 某些 style）把视觉重量分给了背景。
顶刊版一律纯白无网格，需要参考线时只画**那一条**需要的。

检验：图里除了数据本身，还有几种非数据墨迹？多于「轴线 + 必要参考线」就删。

### 2. 颜色要编码结构，不是区分个体

普通版用默认色环（hue 轮转），相邻类别色相接近、明度一致——**颜色只是标签，读不出分组**。
顶刊版手工指定：**同一大组内同色系不同明度，跨大组换色相**，于是颜色本身就画出了层级。
（语料例：18 个细胞类型按 L2/L3/L4/L5/L6 分成 5 组，组内绿→深绿→浅绿，组间绿/黄/蓝/紫/橙。）

有序变量（温度、样本量、迭代轮次）用**单调色标**；类别变量才用离散色。
两个平行系列优先用**实心/空心**区分，比再加一种颜色干净。

检验：把图转成灰度，还能读出分组吗？读不出说明颜色在做装饰而不是编码。

### 3. 轴的尺度比配色重要

语料里最大的一次改观不是换色——是把线性 x 轴换成 **log10**。
普通版 0–1000 线性轴把整族曲线全挤在左边缘 5% 宽度里，看不出任何结构；
换 log 后同一批数据展开成一族有序峰移曲线，规律一眼可见。

数模里同型场景：样本量 n、迭代次数、机时、浓度/密度扫描——**这些天然跨量级的量默认先试 log 轴**。

检验：数据点在轴上的分布是否均匀？挤在一端就换尺度，不要靠放大局部图补救。

### 4. 轴标题写物理量 + 单位，不写变量名

普通版轴标题是 `x`、`y`、`M-type`、`Motif Group`（代码里的列名）。
顶刊版是 `Frequency (Hz)`、`Molar Volume (cm³ mol⁻¹)`、`Output fraction`。

检验：评委不看正文只看这张图，能说出两个轴各是什么量、什么单位吗？

### 5. 图例要排序、要瘦身

普通版图例顺序是字典序（`<5%, ≥30%, 15-30%, 5-15%`）——**语义上是乱的**。
顶刊版按数值单调排；并且**低于阈值的类别直接不画**（语料里 `<5%` 的点 size 设为 `-Inf`），
噪音点从画面里消失，图例里只留一行说明它被略去。

检验：图例条目的顺序有语义吗？有没有条目对应的图元少到看不见？

### 6. 分组用几何分隔，不用更多颜色

顶刊版在组边界画细分隔线（线宽 0.2）、在轴外侧画分组括号线，把 18 个类别切成 5 段。
普通版靠 45° 倾斜的密集标签硬挤。

数模里同型场景：多问结果并排、多档参数分组、算法族对比。

检验：读者要区分两个相邻组，靠的是位置还是靠记住颜色？

### 7. 轴可以搬家

顶刊版把 x 轴标签移到**顶部**并水平排列，因为矩阵型图的行标签在左、列标签在上更符合阅读习惯，
也省掉了 45° 倾斜。matplotlib：`ax.xaxis.set_ticks_position('top')`。

## matplotlib 落地要点（语料是 R，这里是等价实现）

| 语料里的 ggplot 做法 | matplotlib 等价 |
|---|---|
| `theme_bw()` / 去灰底 | `ax.set_facecolor('white')`；`ax.grid(False)`；`ax.spines[['top','right']].set_visible(False)` |
| `scale_fill_manual(values=...)` | 显式传 `color=`／`c=` 列表，**不要用默认色环** |
| `shape = 21, stroke = 0.5`（可填充带边框的点） | `scatter(..., edgecolors='k', linewidths=0.5)`；点重叠时才加 `alpha=0.7`，不重叠就别加——透明度是解决遮挡的，不是默认装饰 |
| `geom_tile()` / `sns.heatmap()` | `im = ax.imshow(M, cmap='RdBu_r')` + `fig.colorbar(im, ax=ax)`。**热图没有色标就是没有量纲**，色标必须带单位 |
| `geom_line(linewidth=)` | 主线 `linewidth>=1.5`；离散采样点才加 `marker`，连续曲线不加——marker 是在标"这里真的测过"，密集曲线上加只会糊成一团 |
| `geom_col()` | 浅填充 + 细白边 `edgecolor='white', linewidth=0.5`，让相邻柱子分开而不靠描粗 |
| `scale_x_log10()` | `ax.set_xscale('log')` |
| `expand = expansion(mult=c(0.08,0.08))` | `ax.margins(0.08)` |
| `coord_cartesian(clip='off')` | `ax.set_clip_on(False)` 或画在 `ax.transAxes` 上 |
| `geom_segment` 画分组括号 | `ax.plot(..., transform=ax.get_xaxis_transform(), clip_on=False)` |
| 中文字体 | 见下方字体栈；`axes.unicode_minus = False` 不可省，否则负号变方框 |

## 中文字体：写成栈，不写成一个名字

只写 `Microsoft YaHei` 在别人机器上就是满图豆腐块。按可用性排一串，matplotlib 会依次回退：

```python
plt.rcParams['font.sans-serif'] = [
    'Microsoft YaHei', 'SimHei',            # Windows
    'PingFang SC', 'Hiragino Sans GB', 'STHeiti', 'Heiti TC', 'Songti SC',  # macOS
    'Noto Sans CJK SC', 'WenQuanYi Zen Hei',                                 # Linux
    'DejaVu Sans',                          # 末级 fallback（无中文，但不至于崩）
]
plt.rcParams['axes.unicode_minus'] = False
plt.rcParams['savefig.dpi'] = 300
plt.rcParams['savefig.bbox'] = 'tight'
```

**检验**：出图后看一眼有没有**豆腐块**（□），并检查日志里的 `Glyph .* missing from font`。
命中就换字体重跑——不要用 `warnings.filterwarnings('ignore')` 把它压掉，那等于把唯一的
报警器关了，最后交上去一篇方框论文。

图里**不写 `set_title()`**——标题由 LaTeX 的 `\caption{}` 承担（论文形态契约的硬条款）。
导出统一 `dpi≥300`、`bbox_inches='tight'`。
