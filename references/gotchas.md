# Known Gotchas

只在下列触发条件命中时读；每条均按“具体发现 -> 通用 pattern -> 后果”记录。

## Green Gates, Wrong Problem
一份测试与门禁全绿的交付仍因退化规模暴露数量级错误 -> 统计证书只能证明所实现问题，不能证明题意和物理口径正确 -> 不让口径撞现实会高置信地交付错答案。

## Semantic Identity
结果曾按数组位置贴标签，旧块顺序变化后把一个场景的数字发给另一场景 -> 行号、块序和显示名不是稳定语义主键 -> 数字、图与正文会彼此一致地指错对象。

## All-or-Nothing Batches
长批因资源耗尽中断且中途零落盘，已花机时全部丢失 -> 长计算是可恢复状态机，不是一次函数调用 -> 没有分块、原子写和恢复扫描会在最缺时间时归零。规范早已写明却无人执行过，直到 `scripts/batch_gate.py` 把它变成退出码：规范写了没有门禁，等于没写。

## Measured Runtime Beats Estimates
逐对象循环按主观估时开跑，真实外推远超预算 -> 复杂度符号不能替代真实内核计时 -> 未在定型前实测会把机时耗尽而没有交付物。

## Generated But Unused Figures
图目录已有多张诊断图，正文只引用其中一张 -> 生成文件不等于建立证据链 -> 未引用、未解读的图既浪费时间又让关键结论失去支撑。

## Self-Issued Gates
交付者另写发射器和检查器后所有 Gate 看似通过 -> 被检实现不能自行定义通过标准 -> 替代官方脚本会制造无法独立复核的确定性。

## Delivery Boundary Leaks
工作区检查通过，组装后的交付包仍含凭据、绝对路径、缓存和缺失文件引用 -> 工作区与交付包是两个安全边界 -> 不在包内复现并扫描会泄密或让他人无法运行。

## Inconclusive Is Not Failure
临界点区间跨阈值后直接改报更保守答案 -> 证据不足与不可行是不同状态 -> 二态化会系统性劣化答案并伪装成稳健。

## Seed-Dependent Answers
同一临界档、两个独立种子族各跑满样本，一族判 614、另一族判 615 -> 阈值附近的档位选择是随机变量，单族结论只是那批随机数的一次实现 -> 不做多种子复核就会把运气当成答案，并且全程没有任何征兆。
触发条件：结论形如「满足阈值的最小/最大档位」。检查动作：`python scripts/seed_gate.py 结果/多种子.json`，退出码非 0 即写 `certificate.resolved=false` 并降到下一档精度报告。

## Random Geometry / Percolation
触发条件仅为“随机几何/渗流类题目”：曾把边界切分后的碎片身份混用，产生单体短路或反向漏边 -> 生成、节点、边和边界判定必须共享同一身份语义 -> 任何混用都会系统性改写连通阈值。

同一触发条件下，Balberg 量级、有限尺寸与细长胞元替代解释曾被固化成通用检查 -> 领域理论和形状实验只能作为候选外部证据，且须先判适用性与排他性 -> 强套会把其他题逼成虚假 N/A，漏做则会把相容性误写成证明。
