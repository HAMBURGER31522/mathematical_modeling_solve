%   2. LaTeX 宏名不能含数字：\qNumOne 合法、\qNum1 非法。台账键一律用纯字母
%      驼峰（qOneThreshold / qTwoRateLow），发射器负责转换。
%   3. 下面用 IfFileExists 保护，但故意让缺失可见：没有台账时正文会打出
%      [NUMBERS-MISSING]，而不是静默编译过去骗自己。
% ---------------------------------------------------------------------------
\IfFileExists{numbers.tex}{%
  \input{numbers.tex}%
}{%
  \newcommand{\NUMBERSMISSING}{\textbf{[NUMBERS-MISSING]}}%
  \typeout{!!! numbers.tex 未找到：先跑 ledger.py --emit-tex}%
}
