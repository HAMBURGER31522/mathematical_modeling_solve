# Gate Triage

1. 建 Task Anchor；从 Gate 记录复制失败命令、退出码、被检对象与预期，不接受摘要式复述。
2. 运行 `python -m pytest scripts/tests/test_contracts.py -q`；契约失败先停用对应“官方”结论，修复归脚本所有者。
3. 原样重跑失败命令，判断是对象缺失、空检查、参数来源、真实红线还是环境阻塞；只修改产生失败证据的上游。
4. R1、R2、R4、R6、R7、R11 或 R13 未解除时停止下游；其余只按规则允许的措辞、精度或范围降级，并写 `结果/降级记录.md`。
5. 用同一官方命令复验；退出码、关键数字和证据路径写回原 Gate。不得用自写脚本、删检查项或白名单整类错误来转绿。
