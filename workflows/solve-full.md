# Full Solve: P0 to P7

- **Anchor**：建 Task Anchor（Goal、Boundaries、Done When），运行 `python scripts/openconf.py`，确认题面、附件、模板与赛事参数可读。
- **P0 读题与体检**：逐问忠实转录；在求解前写 `结果/拆问卡.md`，每问填九字段，按适用性在 expected_outputs 明确对象身份口径；随后初始化 ledger，再逐列体检附件并与题面实测值对照。运行 `python scripts/task_cards.py --cards 结果/拆问卡.md --ledger 结果/results_ledger.json`。
- **P1 口径审定**：只看原题独立重建后对表；每项口径绑定 locator、被否解释、判别实验与对象身份。运行 `rg -n "BLOCKED|UNVERIFIABLE|待附件核验" 结果/拆问卡.md 结果/数据体检.md`，逐条处置命中。
- **P2 选模与 Pilot**：按需读 `references/method-cards.json`；每问的实现来源写“库与 commit / 自研理由 / N/A”之一；用同一数据划分、指标与时间预算真跑两到三个候选及简单 baseline，只从跑通者定案。运行 `python scripts/pilot_gate.py --results 结果/pilot_results.json`。在放大计算前以小规模跑通 P3 到 P7 的最小闭环，确保结果、图、论文、PDF 与复现入口均存在。
- **P3 实现与计算**：共用 `求解/core/`，先独立神谕测试再生产；先算后画。长批必须写成可恢复状态机（每块 ≤500 单元、临时文件 os.replace 原子落盘、启动扫描跳过已完成块），开跑前运行 `python scripts/batch_gate.py 求解/*.py --out 结果/gates/G3-batch.md`，退出码必须为 0。运行 `python scripts/test_inventory.py --tests-dir 求解/tests --report 结果/gates/G3-tests.json`、`python scripts/degenerate.py --fn <模块:函数> --threshold <题面阈值> --n-probe <题面档位>`、`python scripts/sample_gate.py --scenarios 结果/sample-scenarios.json --report 结果/gates/G3-samples.json`。关键结果双路互证；临界/阈值/最优档位答案必须做多种子复核——≥2 个独立种子族各覆盖答案点与相邻档，运行 `python scripts/seed_gate.py 结果/多种子.json --out 结果/gates/G3-seed.md`，退出码非 0 即答案未分辨，写 certificate.resolved=false 并降档报告。入账时：运行 `python scripts/ledger.py --validate 结果/results_ledger.json`、`python scripts/ledger.py --freeze 结果/results_ledger.json`。
- **P4 深度审查**：逐问核声明强度、gap、误差预算、适用家族与外部对照；从代码行复核论文谓词、跨问内核与私货约束。内核或输入改变后运行 `python scripts/ledger.py --stale-check 结果/results_ledger.json --write` 并回 P3。
- **P5 图表**：先写每图目的、ledger 键和正文落点；按需读 `references/figure-style.md` 并打开样例。运行 `python scripts/figqa.py 图/ --tex 论文/*.tex --out 结果/figqa.json --contact 图/_contact.png`，再目检 contact sheet。每张正文图后紧跟一段解读，按“现象—原因—意义”写（图上看出什么 → 为什么会这样 → 因此如何取舍），只写“如图 X 所示”不算解读。
- **P6 论文**：沿 `assets/paper/` 分节装配，按需读 `references/abstract-moves.md`；先生成宏再写文。运行 `python scripts/ledger.py --emit-tex 结果/results_ledger.json -o 论文/numbers.tex` 与 `python scripts/audit_numbers.py --ledger 结果/results_ledger.json --numbers 论文/numbers.tex --tex 论文/*.tex --out 结果/审计报告.md`。检验章依次写双路互证、事实对表、参数灵敏度、样本量与收敛、稳健性对照、适用边界；每问结论块和全文汇总表只引用 authoritative 宏；宏携带证书元数据（下界、n、seed、verdict、resolved、Δ、u），机会约束类数字旁必须出现下界值。模型评价章的缺点按“缺陷—影响—改进”写，并与降级声明逐条一致。
- **P7 编译与打包**：运行 `latexmk -xelatex -halt-on-error -interaction=nonstopmode 论文/main.tex`、`python scripts/latex_gate.py 论文/main.log --pdf 论文/main.pdf --aux 论文/main.aux --tex 论文/main.tex --appendix-label sec:appendix --abstract-label abstract:end`、`python scripts/pkg_scan.py 交付/` 与交付目录内复现入口；命令和退出码写入对应 Gate。
