# Modeling Red Lines: 11 + 2

- **R1 题面口径忠实。** 判据、约束、边界、对象、单位与跨问口径只能来自可定位的题面或附件证据，简化须证明不翻转结论。
  **检验**：随机抽三条模型约束，能否各自指出题面页码、图号或附件单元格，并在共享内核定位同一谓词？
- **R2 证书必须匹配方法家族。** 证书须覆盖该家族的真实风险，选择数据与最终认证数据分离，区间跨阈值只能判 `inconclusive`。
  **检验**：问每个最终结论“证书为何适用于该估计量，认证批是否独立，退出判定是否达标？”
- **R3 最优性措辞不得越级。** 只有完整排除或有效全局界可称全局最优，邻域证据称局部最优，其余只称已搜索集合内最优。
  **检验**：全文搜索 `最优|最低|全局|证明`，每一处能否指到候选范围、下界或排除证据？
- **R4 测试神谕必须独立。** expected 只来自手算、解析解或独立实现，并覆盖原语、统计、论文源与图四层。
  **检验**：随机抽三个测试问“expected 怎么算出？”；回答出现被测函数或换壳调用即失败。
- **R5 分辨率必须有出处。** Δ 依次取自题面精度、待比较目标差的三分之一或决策变量最小单位，认证不确定度须与它对账。
  **检验**：指着每个 Δ 问“它来自题面哪句、哪个方案差或哪个决策单位？”；答不上来即未审定。
- **R6 数字只能单向流动。** 结果由代码进入唯一 authoritative ledger，再生成论文宏，并保持依赖哈希、磁盘结果与论文三向可回读。
  **检验**：运行 `python scripts/ledger.py --validate 结果/results_ledger.json` 与 `python scripts/audit_numbers.py --ledger 结果/results_ledger.json --numbers 论文/numbers.tex --tex 论文/*.tex`。
- **R7 赛制合规阻断提交。** 页数、图数、摘要、模板、命名、匿名与声明只从 `开题.md` 和赛事原文取值。
  **检验**：运行 `python scripts/openconf.py`、`python scripts/latex_gate.py 论文/.latex-build/main.log --pdf 论文/main.pdf --aux 论文/.latex-build/main.aux --tex 论文/main.tex` 与 `python scripts/pkg_scan.py 交付/`。
- **R8/9 每问既是形式化模型也是可复写算法。** 正文须呈现变量、目标或判据、约束，并按论文形态契约给出算法选择五段式、算法对比表及输入、步骤、输出、复杂度。
  **检验**：遮住代码后，读者能否指出三项模型要素并仅凭算法段重写求解过程？
- **R10 数据反推必须有排他性。** 观察只能在替代解释被独立证据排除后升级为结论，否则降为假设或“与观察相容”。
  **检验**：逐条追问“这个观察在 not-X 时会不会同样出现？”；会则不是排他证据。
- **R11 临界、最优和边界答案必须独立复核。** 第二实现须更换算法或判据路径，而非同一代码换参数或随机种子。
  **检验**：两路实现是否共享核心判定代码？若共享，它们不能互相发证书。临界档答案另运行 `python scripts/seed_gate.py 结果/多种子.json`，退出码必须为零——答案随种子漂移即为未分辨。
- **R13 生产批前必须过退化规模检验。** 把规模与判据推向题意可判的退化端点，输出须符合机理且对判据敏感。
  **检验**：运行 `python scripts/degenerate.py --fn <模块:函数> --threshold <题面阈值> --n-probe <题面档位> --out 结果/gates/G3-退化检验.json`，退出码必须为零。
- **H1 题面档位是量级警报器。** 答案明显越出题面档位量级时先回查口径，只有题目要求外推且有依据才例外。
  **检验**：把答案换成题面同一量纲后，能否解释量级差并给出外推证据？
- **H2 多档结果应具有可解释的分辨度。** 全饱和、全零或全相同先按口径或实现异常处理，解析或机理论证成立才可放行。
  **检验**：相邻档差异是否超过各自不确定度；若没有，是否有独立机理论证而非仅扩大样本？
